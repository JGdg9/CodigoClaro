# CódigoClaro

**Plataforma educativa independiente para aprender programación practicando.**

CódigoClaro es un proyecto en desarrollo pensado como apoyo para el alumnado de DAM y DAW. La aplicación, su documentación y sus recursos están agrupados dentro de `CodigoClaro_v3/`.

## Probar la aplicación

[Abre CódigoClaro](https://codigoclaro.onrender.com/).

## Versión vigente

La versión declarada por el paquete de la aplicación es **1.4.2** ([`package.json`](CodigoClaro_v3/package.json)). Consulta las [novedades de v1.4.2](CodigoClaro_v3/docs/NOVEDADES_v1.4.2.md) y el [informe de cambios y funcionalidades](CodigoClaro_v3/docs/INFORME_CAMBIOS_Y_FUNCIONALIDADES.pdf).
