CODIGOCLARO v1.4.2 - EMPEZAR AQUI
=================================

1) Instala Node.js LTS 22.5 o superior: https://nodejs.org/
2) Extrae todo el ZIP a una carpeta.
3) Ejecuta INICIAR_CODIGOCLARO.bat.
4) La primera vez se abre .env. Define ADMIN_EMAIL con el correo permitido para administración y SESSION_SECRET con una cadena aleatoria larga. Guarda y cierra el Bloc de notas.
5) Abre http://localhost:3000 y crea la cuenta que vayas a usar. El registro público siempre crea cuentas de estudiante.
6) Para promover una cuenta a administradora, verifica primero que controlas ese correo y, desde la carpeta CodigoClaro_v3 con acceso a la base local, ejecuta: node scripts/promote-admin.js tu-correo@example.com --confirm. Consulta ADMINISTRACION.md.
7) Para probar desde otro dispositivo, usa solo una red Wi-Fi de confianza y sigue PRUEBA_USUARIOS.md. No abras el puerto al exterior.
8) Para comprobar el código, consulta las instrucciones de contribución del proyecto. El filtro de tecnología de los tests es estricto y no mezcla preguntas de otras tecnologías para completar una cantidad.

No abras index.html con doble clic; el login necesita el servidor. Para detenerlo, vuelve a la ventana de consola y pulsa Ctrl+C.
No compartas .env ni abras el puerto al exterior. La política de privacidad sigue siendo una plantilla que debes completar antes de un piloto formal externo.

9) En Estadísticas puedes iniciar y terminar una sesión de estudio. Los minutos se calculan en el servidor y se guardan en SQLite. No cierres el proceso mientras guardas una sesión.
