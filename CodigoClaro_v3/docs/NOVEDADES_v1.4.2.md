# CódigoClaro v1.4.2 — Reorganización de archivos

## Cambios

- Los PDF públicos se agrupan en `public/temarios/`.
- Las guías para usuarios se agrupan en `public/ayuda/`.
- El catálogo y la biblioteca usan las rutas organizadas de los temarios.
- El servidor mantiene compatibilidad con las URL anteriores de los PDF y de las guías convertidas a Markdown.
- Se amplía la documentación del código y se actualiza el verificador de entrega.
