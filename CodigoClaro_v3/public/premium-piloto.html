Proyecto de muestra

API de tareas de estudio

Diseña un servicio pequeño que permita crear, consultar, completar y borrar tareas. El objetivo del prototipo es probar una ruta de trabajo guiada, no ofrecer código listo para producción.

Tecnologías sugeridas: Node.js, HTTP y SQLite. Puedes hacer primero el diseño en papel o en tu editor local.

Al terminar podrás

Practicar un flujo completo

  • Definir un recurso y sus reglas de validación.
  • Diseñar operaciones CRUD con respuestas HTTP coherentes.
  • Probar casos correctos, datos inválidos y tareas inexistentes.
