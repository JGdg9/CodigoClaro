CÓDIGOCLARO · ENTREGA AMPLIADA DE TEMARIOS Y TESTS

INICIO
1. Extrae el ZIP completo; conserva la estructura de carpetas.
2. En Windows, ejecuta INICIAR_CODIGOCLARO.bat desde la carpeta del proyecto. La aplicación necesita el servidor Node.js.
3. Abre http://localhost:3000 en el navegador y entra en “Rutas PDF” para buscar los temarios.
4. No muevas los PDF: la aplicación usa las rutas public/temarios y docs/temarios. Abrir public/index.html directamente no inicia el servidor ni las funciones de cuenta y progreso.

MATERIAL INCLUIDO
- 15 temas individuales de Java.
- 15 temas individuales de JavaScript.
- 15 temas individuales de Python.
- 15 temas individuales de Kotlin.
- 15 temas individuales de React.
- 6 rutas complementarias de 15 temas: TypeScript, SQL relacional (Oracle/MySQL/PostgreSQL), NoSQL (MongoDB/Firestore/Firebase), backend/API, POO y gestión de bases de datos.
- Los 9 PDFs anteriores, los ejercicios y el IDE integrado.
- Cada tema individual incluye objetivos, conceptos, ejemplo, práctica, solución orientativa y checklist.

EJECUCIÓN Y COSTES
- No se integra ninguna API de pago ni se requieren servicios contratados para leer los PDF.
- La biblioteca PDF no requiere servicios externos. Las cuentas y el progreso se guardan en SQLite local del servidor Node.js; no son una base de datos dentro del navegador.
- JavaScript se ejecuta en el navegador; Pyodide, React/JSX y SQL.js pueden cargar bibliotecas desde CDN y necesitar Internet en el primer uso.
- Java y Kotlin ofrecen editor y análisis estático; no compilan ni envían código a un servicio remoto en esta versión. Node.js se presenta como simulador didáctico, no como runtime real.
- Firestore/MongoDB se presentan como simuladores en el IDE; las conexiones reales requieren motores/configuración propios.

PRUEBAS DE PAQUETE
- Verificación de que los 75 PDF de temas individuales y las 6 rutas complementarias están presentes.
- Verificación de enlaces de PDF en el catálogo del navegador.
- Comprobación de sintaxis JavaScript con Node.js sobre los scripts embebidos.
- Pruebas de ejecución de motores externos no se pueden garantizar sin conexión y configuración en el equipo del usuario.

PRUEBAS RÁPIDAS
Consulta ayuda/GUIA_PRUEBAS_RAPIDAS.md para una lista de comprobación de 10–15 minutos. Ejecuta python verificar_entrega.py para revisar estructura y archivos locales.

NOVEDAD UX: abre "Plan de estudio" para seguir un plan semanal de tareas, marcar sesiones, consultar el progreso del plan y exportarlo a JSON. El plan se guarda en este navegador y es independiente de las notas de ejercicios.

VERIFICACIÓN: ejecuta `python verificar_entrega.py` desde esta carpeta. Comprueba la estructura, los PDF, enlaces locales, funciones clave y sintaxis JavaScript si Node.js está instalado. No sustituye las pruebas manuales de cada motor.
