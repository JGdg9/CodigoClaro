# CódigoClaro

CódigoClaro es una plataforma educativa en desarrollo para practicar programación con temarios, ejercicios, tests y seguimiento del aprendizaje.

## Secciones

- **Biblioteca:** busca por tecnología y consulta los temarios PDF.
- **Aula:** practica con ejercicios, tests e IDE didáctico.
- **Plan de estudio:** organiza tareas y sesiones.
- **Cuenta:** consulta y exporta tu progreso o elimina la cuenta.

El acceso a cuentas requiere el servidor de la aplicación. La demo estática de la biblioteca no ofrece inicio de sesión ni progreso sincronizado.

## Privacidad y límites

Consulta la [información de privacidad](/privacidad) y las [condiciones](/condiciones). CódigoClaro gestiona los datos. El registro no verifica el correo y no hay recuperación automática de contraseña.

Java se ejecuta en un servicio externo únicamente tras el consentimiento de la sesión; el código fuente y la entrada estándar se envían a ese servicio. No uses datos personales, claves ni código confidencial. Otros motores pueden ser simulaciones o análisis estático.

Para iniciar una instalación local, consulta [Empezar aquí](EMPEZAR_AQUI.md). Para los detalles de Java y los otros motores, lee [IDE integrado](LEEME_IDE.md).
