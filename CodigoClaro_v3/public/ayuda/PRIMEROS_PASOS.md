# Primeros pasos con CódigoClaro

## Prueba la plataforma

1. Abre http://localhost:3000.
2. Inicia sesión o crea una cuenta de prueba si el registro está abierto. Usa datos ficticios y no compartas la contraseña.
3. En **Temarios**, filtra por tecnología, abre un tema y marca el progreso.
4. Haz un test y revisa las explicaciones.
5. En **Plan de estudio**, añade una tarea, márcala como hecha y recarga la página.
6. En **Feedback**, envía una sugerencia o comunica un error.
7. En **Cuenta**, prueba exportar tus datos o eliminar la cuenta de prueba.
8. Abre el aula y practica con un ejercicio. Con la sesión iniciada, el progreso guardado puede sincronizarse con tu cuenta.

Los ejercicios y tests de demostración sin cuenta no guardan datos en el servidor.

## Qué esperar del IDE

- JavaScript se ejecuta en el navegador.
- React/JSX ofrece una vista previa estática local; los eventos y efectos no se ejecutan y no hay interactividad.
- Algunas bibliotecas generales del IDE pueden requerir conexión a Internet.
- SQL usa SQLite en un entorno didáctico; no equivale a Oracle, MySQL ni PostgreSQL.
- MongoDB y Firestore son simuladores y no se conectan a servicios cloud reales.
- Java se ejecuta en Judge0 por HTTPS después de tu consentimiento. Se envían el código y la entrada del programa a ese servicio; usa ejemplos sin datos personales ni secretos.
- Kotlin ofrece análisis estático. Node.js usa un simulador y PL/SQL necesita una base Oracle para ejecutarse.

No introduzcas contraseñas, tokens, claves API ni código confidencial en el IDE. Los motores externos pueden tener límites y no sustituyen una instalación local completa.
