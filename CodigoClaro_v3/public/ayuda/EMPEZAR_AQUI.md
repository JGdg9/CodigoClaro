# Empieza con CódigoClaro

1. Descarga el ZIP y conserva la estructura de carpetas.
2. Instala Node.js LTS 22.5 o superior.
3. Ejecuta `INICIAR_CODIGOCLARO.bat` desde la carpeta del proyecto.
4. Si es el primer inicio, sigue las indicaciones que muestre el lanzador. No compartas archivos de configuración ni credenciales.
5. Abre http://localhost:3000 e inicia sesión o crea una cuenta si el registro está abierto.
6. Entra en **Rutas PDF** para consultar los temarios, o abre el **Aula** para practicar y usar el IDE.
7. En **Espacio de estudio** puedes organizar sesiones y revisar tu progreso.

No abras `index.html` con doble clic: las funciones de cuenta necesitan la aplicación en marcha. Si el registro está cerrado, puedes iniciar sesión con una cuenta existente cuando el servicio esté disponible.

Para probar la aplicación, usa datos ficticios y no compartas contraseñas ni información personal.
