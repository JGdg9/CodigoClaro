Si algo falla

  1. Comprueba que extrajiste el ZIP completo y que los PDF están junto a los HTML.
  2. Prueba Chrome o Edge actualizados.
  3. Las funciones Pyodide, React y el resaltado pueden necesitar conexión para descargar sus bibliotecas.
  4. Java/Kotlin/Node.js requieren configurar explícitamente un servicio compatible si quieres ejecución remota.
  5. No desactives el antivirus ni compartas contraseñas, tokens o claves API.
