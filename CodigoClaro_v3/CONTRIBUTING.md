# Contribuir a CódigoClaro

Gracias por ayudar a mejorar los materiales. Antes de proponer cambios:

1. Describe el problema o la mejora con un caso reproducible.
2. Para erratas de un temario, indica tecnología, tema, página, versión del runtime y fuente oficial pertinente.
3. No copies contenido protegido de manuales o cursos. Resume con tus propias palabras y cita documentación primaria.
4. Si cambias el servidor, añade o actualiza pruebas en `tests/`.
5. Ejecuta `node --check server.js`, `npm test` y `python verificar_entrega.py` antes de abrir la propuesta.
6. No incluyas `.env`, bases de datos, datos personales ni credenciales.

Las propuestas que afecten a autenticación, permisos, privacidad o seguridad deben explicar también los riesgos y la forma de validarlos.
